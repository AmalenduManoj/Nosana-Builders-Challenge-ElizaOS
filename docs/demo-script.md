# 60-Second Demo Script

## Goal
Show one complete task-automation cycle in under 60 seconds.

## Script
1. Open the deployed app URL.
2. Prompt: "I have 2.5 hours before 6pm. I need to finish my resume, prep for a call, and clear urgent email. Build my plan."
3. Highlight the generated plan with priorities and time blocks.
4. Prompt: "My call moved earlier. Reprioritize quickly."
5. Highlight the updated timeline and trade-off explanation.
6. Prompt: "Draft two reminder messages: one for my call prep and one for resume final review."
7. Show reminder output and end on one clear next action.

## Narration (short)
"This is TaskForge, my personal task automation agent built on ElizaOS and deployed on Nosana. It turns vague goals into executable plans, adapts when priorities shift, and drafts reminders instantly. The deployment runs on decentralized infrastructure and is publicly accessible for judging."
